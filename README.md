# 校园跑工具 · 发布与更新

本仓库只存放三个独立应用的发布包与版本信息，供客户端检查更新与下载。

## 客户端

| 应用 | Windows | Android |
| --- | --- | --- |
| 运动世界工具 | `SportsWorldTool.exe` | `SportsWorldTool-arm64-v8a.apk` |
| 闪动校园工具 | `ShandongCampusTool.exe` | `ShandongCampusTool-arm64-v8a.apk` |
| 红蜻蜓工具 | `RedDragonflyTool.exe` | `RedDragonflyTool-arm64-v8a.apk` |

- 桌面版直接运行 exe；Android 版为 arm64-v8a，最低 Android 8.0（API 26）。
- 首次启动需要输入卡密激活，一份卡密绑定一台设备。
- 客户端启动时会读取本仓库最新 Release 的版本号：**低于该版本将无法使用**，请保持更新。

## 版本

最新版本以 Release 标签为准（当前 `v0.3.0`）。

## 说明

- 发布包未包含任何账号凭据或本地配置。
- 卡密、解绑与版本策略由管理端维护。
